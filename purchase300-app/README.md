# Purchase Ledger 300 Limited — সম্পূর্ণ সেটআপ গাইড

এই প্রজেক্টে ৩টা পেজ আছে:
- `/` → Login পেজ
- `/admin` → শুধু Admin এর জন্য — এখানে Excel আপলোড করলে সবার Dashboard-এ ডেটা আপডেট হয়ে যাবে
- `/dashboard` → আসল Dashboard, যেটা আগে আপনার একার browser এ ছিল, এখন সবাই দেখতে পাবে (login করার পর)

ডেটা এখন Vercel Blob Storage-এ জমা থাকে, তাই Admin একবার আপলোড করলেই সব ইউজার সেই একই ডেটা দেখতে পাবে — বারবার আপলোড করতে হবে না।

বিস্তারিত ধাপগুলো নিচে দেওয়া হলো।
